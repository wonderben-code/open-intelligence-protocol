# The A2A project's JSON Schema

`a2a.schema.json` is the JSON Schema bundle of A2A 1.0.1, as the A2A project publishes it: "Non-normative JSON Schema bundle extracted from proto definitions". The tests of this package validate what the gateway puts on the wire against it.
